# 🛒 StationeryStore

Website bán đồ dùng học tập – HTML, CSS, JavaScript thuần.

## 📁 Cấu trúc thư mục

```
StationeryStore/
├── index.html
├── pages/
│   └── auth/
│       └── login.html
├── css/
│   └── auth/
│       └── login.css
├── js/
│   └── auth/
│       ├── auth-tabs.js
│       └── login.js
└── assets/             ← Ảnh, font, icon
```

Các màn hình được nhóm theo tính năng trong từng loại file (ví dụ `auth`), giúp
dễ thêm các nhóm như `products` hoặc `cart` sau này.

## 🚀 Cách chạy

Mở file `index.html` trực tiếp trên trình duyệt hoặc dùng extension **Live Server** (VS Code).

## 🛠️ Công nghệ

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage (giỏ hàng)
